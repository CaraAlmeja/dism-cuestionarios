# DISM · T1 · Aplicaciones multiplataforma

Elige una única respuesta por pregunta.

1. Una app móvil muestra HTML, CSS y JavaScript dentro de una WebView instalada con la app. ¿Qué enfoque utiliza?

   A) Desarrollo con controles nativos de MAUI
   B) Desarrollo nativo con Kotlin
   C) Desarrollo nativo con Swift
   D) Desarrollo híbrido

2. Un equipo utiliza JavaScript con React Native y componentes de interfaz nativos. ¿Cómo se clasifica este enfoque en el tema?

   A) PWA por compartir el código
   B) Multiplataforma con interfaz nativa
   C) Web tradicional por utilizar React
   D) Híbrido por utilizar JavaScript

3. Un equipo domina HTML, CSS y JavaScript y quiere una app sencilla para iOS y Android con una base compartida. ¿Qué ventaja le aporta el enfoque híbrido?

   A) Reutilizar conocimientos web y reducir duplicación de desarrollo
   B) Sustituir las pruebas de dispositivo por pruebas de navegador
   C) Mantener dos bases de código independientes con el mismo lenguaje
   D) Compilar el HTML en controles UIKit y Android Views

4. Una app híbrida necesita un sensor nuevo que todavía no dispone de integración. ¿Qué dependencia puede retrasar su implementación?

   A) La disponibilidad o creación de un plugin para ese sensor
   B) La imposibilidad de instalar apps híbridas desde tiendas
   C) La obligación de sustituir CSS por XAML
   D) La necesidad de convertir todo el código a HTML estático

5. ¿Qué pareja de lenguaje y entorno corresponde al desarrollo específico de aplicaciones iOS descrito en el tema?

   A) Swift y Xcode
   B) Kotlin y Android Studio
   C) C# y una WebView de Cordova
   D) Dart y Android Studio como SDK exclusivo de Apple

6. En el contexto histórico del temario, ¿qué describe mejor a Xamarin?

   A) Un SDK de Google cuyo lenguaje principal es Dart
   B) Una herramienta para crear apps nativas compartiendo código C#
   C) Una tecnología de JetBrains centrada en compartir código Kotlin
   D) Un framework web basado exclusivamente en HTML y CSS

7. ¿Para qué se utiliza Apache Cordova en el modelo de desarrollo del tema?

   A) Compartir lógica Kotlin conservando interfaces por plataforma
   B) Crear interfaces nativas usando C# y XAML
   C) Compilar Dart para dibujar interfaces con widgets
   D) Empaquetar apps web móviles y acceder al dispositivo mediante plugins

8. ¿Qué es Ionic según el temario?

   A) Un framework de interfaces y apps multiplataforma con tecnologías web
   B) Un lenguaje que sustituye a JavaScript en el navegador
   C) Una herramienta de Apple exclusiva para apps iOS
   D) Un SDK que obliga a escribir todas las vistas en Dart

9. En una app Ionic, ¿qué papel cumple Capacitor cuando se necesita usar la cámara?

   A) Servir exclusivamente como sistema de estilos CSS
   B) Ofrecer integración con funciones nativas mediante plugins
   C) Sustituir JavaScript por el lenguaje Dart
   D) Transformar toda la interfaz en controles XAML

10. ¿Qué relación mantiene TypeScript con JavaScript?

   A) Añade capacidades como tipos y se transpila a JavaScript
   B) Es un subconjunto que elimina las funciones de JavaScript
   C) Es código máquina que ejecuta directamente la GPU
   D) Es un lenguaje exclusivo de bases de datos relacionales

11. ¿Qué caracteriza a una Progressive Web App (PWA)?

   A) Una interfaz que exige controles nativos de UIKit
   B) Una app web con capacidades como instalación y funcionamiento sin conexión
   C) Un ejecutable de escritorio escrito obligatoriamente en Rust
   D) Una app que solo puede obtenerse desde una tienda móvil

12. Una PWA quiere abrir los recursos de estudio ya descargados cuando no hay conexión. ¿Qué mecanismo del tema lo hace posible?

   A) Una suscripción a la tienda de aplicaciones
   B) Una hoja de estilos con diseño adaptable
   C) Un service worker con una estrategia de caché
   D) Un manifiesto que convierte automáticamente la web en código Swift

13. ¿Qué es .NET MAUI?

   A) Un framework híbrido que exige HTML para todas las interfaces
   B) Un compilador de Dart mantenido por Google
   C) Un reproductor de streaming adaptativo para navegadores
   D) Un framework para apps nativas móviles y de escritorio con C# y XAML

14. ¿Qué combinación identifica a Flutter en el temario?

   A) Framework de Meta y lenguaje JavaScript
   B) Framework de Microsoft y lenguaje C#
   C) SDK de Google y lenguaje Dart
   D) Tecnología de JetBrains y lenguaje Kotlin

15. Un equipo domina React y quiere crear apps iOS y Android con interfaz nativa usando JavaScript o TypeScript. ¿Qué herramienta encaja directamente?

   A) .NET MAUI
   B) Apache Cordova
   C) Flutter
   D) React Native

16. Un equipo quiere compartir reglas de negocio en Kotlin y conservar una interfaz diferente para iOS y Android. ¿Qué tecnología se ajusta a ese objetivo?

   A) Flutter con widgets Dart
   B) Ionic con una interfaz HTML compartida

17. ¿Qué herramienta del temario combina una interfaz de tecnologías web con un núcleo en Rust para crear apps ligeras?

   A) Kotlin Multiplatform
   B) Tauri
   C) Xamarin
   D) Flutter

18. Un equipo de C# y XAML necesita llevar la misma app también al navegador mediante WebAssembly. ¿Qué alternativa destaca el tema?

   A) Apache Cordova como compilador de C# a WebAssembly
   B) .NET MAUI como destino web integrado del tema
   C) Uno Platform
   D) React Native como framework de XAML

19. Una app necesita aprovechar funciones muy específicas del dispositivo y prioriza la integración con su plataforma. ¿Qué enfoque del tema ofrece el acceso más directo?

   A) Una PWA mediante las APIs compatibles del navegador
   B) Desarrollo híbrido con plugins para sus capacidades de hardware
   C) Desarrollo específico con las herramientas nativas de la plataforma

   A) Probar una única plataforma y extrapolar los resultados al resto
   B) Verificar solo la compilación para cada sistema operativo
   C) Probar y ajustar el comportamiento en cada plataforma objetivo

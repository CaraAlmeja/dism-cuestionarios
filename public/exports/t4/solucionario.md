# Solucionario: DISM · T4 · OpenAPI

## 1. D) Un estándar abierto para describir interfaces de APIs HTTP

OpenAPI Specification permite describir operaciones, parámetros, respuestas y otros aspectos de una API HTTP de forma comprensible para personas y herramientas. Es independiente del lenguaje de implementación y suele expresarse en JSON o YAML.

Fuente: OpenAPI Initiative · What is OpenAPI? · What is OpenAPI?. Contraste: https://www.openapis.org/what-is-openapi

Distractores:

- A) OpenAPI describe una interfaz; no es por sí mismo el servidor que la implementa.
- B) No es un protocolo multimedia como RTP, sino un estándar de descripción de APIs.
- C) La descripción es independiente del lenguaje de implementación.
